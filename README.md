# SentinelChain AI

### From Alert to Attack Story

SentinelChain is an AI-assisted SOC investigation system that takes security
alerts generated by Wazuh and processes them through a structured chain of
specialized investigation agents to produce an explainable security
assessment.

> **Wazuh detects the event. SentinelChain investigates the event.**

## Investigation Pipeline

```text
Wazuh Alert
    ↓
Alert Triage
    ↓
Evidence Analysis
    ↓
Threat Intelligence
    ↓
Correlation
    ↓
Investigation
    ↓
Counter-Analysis
    ↓
Final Verdict
